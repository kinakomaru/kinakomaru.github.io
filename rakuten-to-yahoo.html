作業手順

  • Sheets("data.csv") を Activate
    data.csv シートを操作対象にするため
  • 「HB列項目選択肢を全角スペースに変換する」を実行
    半角スペースの不一致を防ぎ、オプション抽出の精度を上げるため
  • 「シートを削除する」を実行
    不要なシートをクリアし、後続処理での混乱を防ぐため
  • 「★マクロ実行その1」を実行
    C～L 列の各種データを整形・抽出し、Yahoo 形式に合わせるため
  • 「★マクロ実行その2」を実行
    在庫・画像・説明文などの最終整形を行い、CSV 用データを完成させるため
  • 「option_csv作成」を実行
    オプション情報だけを抜き出した CSV を生成し、別途管理用に出力するため
  • 「在庫データ転記」を実行
    最新の在庫数を Yahoo データに反映し、出品ミスを防ぐため
  • メッセージボックスで「処理が完了しました。」を表示
    ユーザーに処理の完了を通知し、次のアクションを促すため
1. Activate data.csv sheet
2. Convert HB欄 options → 全角スペース
3. Delete unnecessary sheets
4. Run “★マクロ実行その1”
5. Run “★マクロ実行その2”
6. Create option_csv
7. Transfer inventory data
8. Show completion message
